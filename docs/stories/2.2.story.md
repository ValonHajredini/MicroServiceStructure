# Story 2.2: Login UI & Token Management

## Status
Draft

## Story

**As a** returning user,
**I want** to login and access my dashboard,
**so that** I can use platform services.

## Acceptance Criteria

1. Angular login form at mydomain.com/login with email and password fields
2. Form submission calls POST /auth/login, receives JWT token
3. JWT stored in localStorage with key 'auth_token'
4. HttpInterceptor automatically adds Authorization: Bearer <token> header to all API requests
5. Invalid credentials display error message: "Invalid email or password"
6. Successful login redirects to /dashboard
7. "Forgot password?" link navigates to /forgot-password

### Architecture Context

**Service**: Core Service (Core UI + Core API)  
[Source: architecture/component-architecture.md#core-service]

**Authentication Flow**:  
[Source: architecture/authentication-multi-tenancy.md#jwt-based-sso-flow]

1. User submits email/password from login form
2. Angular calls POST /api/v1/auth/login
3. Core Service validates credentials
4. JWT generated with claims: userId, email, tenantId, roles, enabledServices

### HTTP Interceptor Implementation

[Source: AC 4, architecture/authentication-multi-tenancy.md#accessing-notes-service]

The interceptor must:
1. Check if request URL requires authentication (exclude /login, /register)
2. Retrieve JWT from localStorage
3. Clone the request and add Authorization header
4. Pass modified request to next handler

**Example Implementation**:
```typescript
@Injectable()
export class AuthInterceptor implements HttpInterceptor {
  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {
    // Skip auth endpoints
    const skipUrls = ['/auth/login', '/auth/register'];
    if (skipUrls.some(url => req.url.includes(url))) {
      return next.handle(req);
    }

    // Get token from localStorage
    const token = localStorage.getItem('auth_token');
    
    // Clone request and add Authorization header if token exists
    if (token) {
      const clonedReq = req.clone({
        setHeaders: {
          Authorization: `Bearer ${token}`
        }
      });
      return next.handle(clonedReq);
    }

    return next.handle(req);
  }
}
```

**Registration in App Config**:
```typescript
// app.config.ts or main.ts
export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient(
      withInterceptors([authInterceptor])
    ),
    // ... other providers
  ]
};
```

### Auth Service Structure

[Source: Angular best practices, architecture patterns]

**Auth Service Methods**:
- `login(email: string, password: string): Observable<AuthResponse>`
- `logout(): void`
- `isAuthenticated(): boolean` (check if token exists)
- `getToken(): string | null`
- `getCurrentUser(): User | null`

**Example**:
```typescript
@Injectable({ providedIn: 'root' })
export class AuthService {
  private readonly TOKEN_KEY = 'auth_token';
  private currentUserSubject = new BehaviorSubject<User | null>(null);
  
  constructor(private http: HttpClient) {}

  login(email: string, password: string): Observable<AuthResponse> {
    return this.http.post<AuthResponse>(
      `${environment.apiUrl}/api/v1/auth/login`,
      { email, password }
    );
  }

  logout(): void {
    localStorage.removeItem(this.TOKEN_KEY);
    this.currentUserSubject.next(null);
  }

  getToken(): string | null {
    return localStorage.getItem(this.TOKEN_KEY);
  }

  isAuthenticated(): boolean {
    return !!this.getToken();
  }
}
```

### Security Considerations

[Source: architecture/authentication-multi-tenancy.md#security-considerations]

1. **Password Visibility**: Add toggle to show/hide password (optional UX enhancement)
2. **HTTPS Required**: Production must use HTTPS to protect JWT in transit
3. **Token Expiration**: JWT expires after 24 hours (backend enforces this)
4. **No Token in URL**: Never pass JWT in query parameters
5. **XSS Protection**: Angular's built-in sanitization helps prevent XSS attacks

### JWT Validation

[Source: architecture/authentication-multi-tenancy.md#jwt-validation-in-each-service]

Backend services validate JWT on each request:
- Verify signature using shared JWT_SECRET
- Check expiration time
- Extract tenant context
- Return 401 if invalid or expired

Frontend should handle 401 responses by redirecting to login.
