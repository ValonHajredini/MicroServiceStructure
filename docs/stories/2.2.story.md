### HTTP Interceptor Implementation

[Source: AC 4, architecture/authentication-multi-tenancy.md#accessing-notes-service]

The interceptor must:
1. Check if request URL requires authentication (exclude /login, /register)
2. Retrieve JWT from localStorage
3. Clone the request and add Authorization header
4. Pass modified request to next handler

**Example Implementation**:
```typescript
@Injectable()
export class AuthInterceptor implements HttpInterceptor {
  intercept(req: HttpRequest<any>, next: HttpHandler): Observable<HttpEvent<any>> {
    // Skip auth endpoints
    const skipUrls = ['/auth/login', '/auth/register'];
    if (skipUrls.some(url => req.url.includes(url))) {
      return next.handle(req);
    }

    // Get token from localStorage
    const token = localStorage.getItem('auth_token');
    
    // Clone request and add Authorization header if token exists
    if (token) {
      const clonedReq = req.clone({
        setHeaders: {
          Authorization: `Bearer ${token}`
        }
      });
      return next.handle(clonedReq);
    }

    return next.handle(req);
  }
}
```

**Registration in App Config**:
```typescript
// app.config.ts or main.ts
export const appConfig: ApplicationConfig = {
  providers: [
    provideHttpClient(
      withInterceptors([authInterceptor])
    ),
    // ... other providers
  ]
};
```

### Auth Service Structure

[Source: Angular best practices, architecture patterns]

**Auth Service Methods**:
- `login(email: string, password: string): Observable<AuthResponse>`
- `logout(): void`
- `isAuthenticated(): boolean` (check if token exists)
- `getToken(): string | null`
- `getCurrentUser(): User | null`

**Example**:
```typescript
@Injectable({ providedIn: 'root' })
export class AuthService {
  private readonly TOKEN_KEY = 'auth_token';
  private currentUserSubject = new BehaviorSubject<User | null>(null);
  
  constructor(private http: HttpClient) {}

  login(email: string, password: string): Observable<AuthResponse> {
    return this.http.post<AuthResponse>(
      `${environment.apiUrl}/api/v1/auth/login`,
      { email, password }
    );
  }

  logout(): void {
    localStorage.removeItem(this.TOKEN_KEY);
    this.currentUserSubject.next(null);
  }

  getToken(): string | null {
    return localStorage.getItem(this.TOKEN_KEY);
  }

  isAuthenticated(): boolean {
    return !!this.getToken();
  }
}
```
