# Story 4.6: Kanban API - Real-Time Updates Strategy

## Status
Approved (Decision needed)

## Prerequisites

- [ ] **Implementation status: Not yet implemented** (No code exists for real-time updates)
- [ ] **Decision required by Week 12: WebSocket vs SSE vs Polling**
  - Evaluate infrastructure constraints
  - Consider complexity vs. benefit trade-offs
  - Document decision rationale before implementation
- [ ] **Integration with JWT authentication required**
  - WebSocket handshake must validate JWT token
  - Extract tenantId from JWT for room scoping

  - Users only receive updates for boards they can access
  - Filter events by tenant_id and board_id

## Story

**As a** developer,
**I want** to implement real-time board updates,
**so that** team members see changes within 5 seconds.

## Acceptance Criteria

1. Decision implemented: WebSocket, Server-Sent Events, or Polling (decided by Week 12)
2. If WebSocket: Socket.io or native WebSocket server configured
3. If Polling: GET /boards/:id/updates?since=timestamp endpoint returns changes
4. Board update events: task created/moved/updated, column added/reordered, comment added
5. Client receives updates and reflects changes without full page reload
6. Updates scoped to tenant and board (users only see their board's changes)
7. Fallback to polling if WebSocket connection fails

### WebSocket Implementation (If Chosen)

**Socket.io Setup**:  
[Source: NestJS WebSocket documentation]

```typescript
// kanban.gateway.ts
@WebSocketGateway({
  namespace: '/kanban',
  cors: {
    origin: ['http://localhost:4200', 'https://kanban.mydomain.com']
  }
})
export class KanbanGateway {
  @WebSocketServer()
  server: Server;

  handleConnection(client: Socket) {
    // Extract tenant_id and board_id from handshake
    // Join room: `board:{boardId}`
  }

  emitTaskCreated(boardId: string, task: Task) {
    this.server.to(`board:${boardId}`).emit('task:created', task);
  }
}
```

### Polling Implementation (If Chosen)

**Endpoint**: GET /api/v1/boards/:id/updates?since=2025-01-14T10:00:00Z

**Query Changes Since Timestamp**:  
- Tasks: WHERE updated_at > since OR created_at > since
- Columns: WHERE updated_at > since OR created_at > since
- Comments: WHERE created_at > since
