## Story

**As a** user,
**I want** to create and manage columns within boards,
**so that** I can define my workflow stages.

## Acceptance Criteria

1. POST /boards/:boardId/columns endpoint creates column with title, position
2. Columns ordered by position field (auto-incremented if not specified)
3. GET /boards/:id includes columns array sorted by position
4. PATCH /columns/:id endpoint updates title, position, wip_limit
5. DELETE /columns/:id moves tasks to first column then deletes column
6. Reordering columns updates position values maintaining sort order
7. WIP limit validation: Cannot move task to column exceeding limit (optional enforcement)

## Dev Notes

### Architecture Context

**Service**: Kanban Service API  
[Source: architecture/component-architecture.md#kanban-service]

**Column Management**:  
Columns belong to boards and are ordered by position. Position is an integer that determines display order.

**Position Auto-Assignment**:  
If position not provided, assign max(position) + 1 for the board.

**Task Migration on Column Delete**:  
When deleting a column, all tasks move to the first column (lowest position) to prevent orphaned tasks.

### API Endpoints

**POST /api/v1/boards/:boardId/columns**  
Create column

Request:
```json
{
  "title": "In Progress",
  "position": 1,
  "wip_limit": 5
}
```

**PATCH /api/v1/columns/:id**  
Update column

Request:
```json
{
  "title": "Updated Title",
  "position": 2,
  "wip_limit": 10
}
```

**DELETE /api/v1/columns/:id**  
Delete column (moves tasks to first column)

**PATCH /api/v1/boards/:boardId/columns/reorder**  
Reorder columns

Request:
```json
{
  "columnIds": ["col-uuid-2", "col-uuid-1", "col-uuid-3"]
}
```
