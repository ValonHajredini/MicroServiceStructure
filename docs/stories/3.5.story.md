# Story 3.5: Notes API - Full-Text Search

## Status
Draft

## Story

**As a** user,
**I want** to search notes by title and content,
**so that** I can quickly find information.

## Acceptance Criteria

1. GET /notes/search?q=query endpoint searches title and content fields
2. Uses PostgreSQL full-text search (to_tsvector/to_tsquery)
3. Results ranked by relevance, paginated (20 per page)
4. Search scoped to tenant_id automatically
5. Supports multi-word queries with AND logic
6. Deleted notes excluded from search results
7. Response includes matching snippets with highlighted query terms

### PostgreSQL Full-Text Search

**Key Functions**:  
[Source: AC 2 and PostgreSQL documentation]

1. **to_tsvector**: Converts document to searchable tokens
   ```sql
   to_tsvector('english', title || ' ' || content)
   ```

2. **plainto_tsquery**: Converts plain text query to tsquery (safe, no injection)
   ```sql
   plainto_tsquery('english', 'project requirements')
   -- Results in: 'project' & 'requirements'
   ```

3. **ts_rank**: Calculates relevance score
   ```sql
   ts_rank(tsvector, tsquery)
   -- Returns float between 0 and 1
   ```

4. **ts_headline**: Generates highlighted snippet
   ```sql
   ts_headline('english', content, tsquery, 'options')
   -- Options: MaxWords, MinWords, ShortWord, HighlightAll
   ```

**Full Search Query**:

```sql
SELECT 
    id,
    title,
    ts_rank(
        to_tsvector('english', title || ' ' || COALESCE(content, '')), 
        plainto_tsquery('english', 'search term')
    ) as rank,
    ts_headline(
        'english',
        COALESCE(content, ''),
        plainto_tsquery('english', 'search term'),
        'MaxWords=50, MinWords=20, ShortWord=3, HighlightAll=FALSE'
    ) as snippet
FROM notes
WHERE 
    tenant_id = 'tenant-uuid'
    AND deleted_at IS NULL
    AND to_tsvector('english', title || ' ' || COALESCE(content, '')) @@ plainto_tsquery('english', 'search term')
ORDER BY rank DESC, updated_at DESC
LIMIT 20 OFFSET 0;
```

### TypeORM Implementation

**Search Service Method**:

```typescript
// notes.service.ts
async search(
  query: string,
  tenantId: string,
  options: { page?: number; limit?: number }
): Promise<PaginatedResult<SearchResult>> {
  const { page = 1, limit = 20 } = options;
  
  // Sanitize query
  const sanitizedQuery = query.trim();
  if (!sanitizedQuery || sanitizedQuery.length < 1) {
    throw new BadRequestException('Search query cannot be empty');
  }
  
  // Build full-text search query
  const queryBuilder = this.notesRepo.createQueryBuilder('note')
    .where('note.tenant_id = :tenantId', { tenantId })
    .andWhere('note.deleted_at IS NULL')
    .andWhere(
      "to_tsvector('english', note.title || ' ' || COALESCE(note.content, '')) @@ plainto_tsquery('english', :query)",
      { query: sanitizedQuery }
    );
  
  // Add rank and snippet
  queryBuilder
    .addSelect(
      "ts_rank(to_tsvector('english', note.title || ' ' || COALESCE(note.content, '')), plainto_tsquery('english', :query))",
      'rank'
    )
    .addSelect(
      "ts_headline('english', COALESCE(note.content, ''), plainto_tsquery('english', :query), 'MaxWords=50, MinWords=20')",
      'snippet'
    )
    .orderBy('rank', 'DESC')
    .addOrderBy('note.updated_at', 'DESC');
  
  // Get total count
  const total = await queryBuilder.getCount();
  
  // Apply pagination
  const results = await queryBuilder
    .skip((page - 1) * limit)
    .take(limit)
    .getRawAndEntities();
  
  // Build response
  const searchResults = results.entities.map((note, index) => ({
    id: note.id,
    title: note.title,
    snippet: results.raw[index].snippet,
    rank: parseFloat(results.raw[index].rank),
    folder_id: note.folder_id,
    is_pinned: note.is_pinned,
    updated_at: note.updated_at
  }));
  
  return {
    data: searchResults,
    meta: {
      query: sanitizedQuery,
      page,
      limit,
      total,
      totalPages: Math.ceil(total / limit)
    }
  };
}
```

**Query Performance Tips**:
1. Always use plainto_tsquery (NOT to_tsquery) for user input
2. Use COALESCE for nullable fields
3. Add tenant_id and deleted_at filters first (most selective)
4. Limit results per page (default 20, max 100)
5. Consider query timeout for very broad searches

### Multi-Word Query Logic

**plainto_tsquery Behavior**:  
[Source: AC 5]

```sql
-- User query: "project requirements"
plainto_tsquery('english', 'project requirements')
-- Results in: 'project' & 'requirements'
-- Matches documents containing BOTH terms

-- User query: "detailed project requirements documentation"
plainto_tsquery('english', 'detailed project requirements documentation')
-- Results in: 'detail' & 'project' & 'requir' & 'document'
-- (stemmed versions with stop words removed)
```

**Stop Words**: PostgreSQL automatically filters common words (the, and, or, etc.)

**Stemming**: Words are reduced to root form (requirements → requir, running → run)

### Security Considerations

**SQL Injection Prevention**:  
[Source: AC 2, 5]

- ALWAYS use plainto_tsquery (NOT to_tsquery)
- plainto_tsquery treats input as plain text (safe)
- to_tsquery requires special syntax and is vulnerable to injection
- Use parameterized queries (:query in TypeORM)

**Example of UNSAFE (DO NOT USE)**:

```typescript
// UNSAFE - DO NOT DO THIS
.where(`to_tsvector('english', title) @@ to_tsquery('english', '${query}')`)
```

**Example of SAFE (USE THIS)**:

```typescript
// SAFE - Use plainto_tsquery with parameters
.where(
  "to_tsvector('english', title) @@ plainto_tsquery('english', :query)",
  { query: sanitizedQuery }
)
```
