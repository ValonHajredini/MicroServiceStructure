# Story 2.8: User & Team Management UI

## Status
Ready for Review (QA Fixes Applied)

## Story

**As a** tenant admin,
**I want** to view and manage team members,
**so that** I can control who has access to my organization.

## Acceptance Criteria

1. GET /tenants/:id/users endpoint returns all users in tenant with roles
2. Team management page displays user list with: name, email, role, status
3. Admin can change user role (admin ↔ user) via PATCH /users/:id/role
4. Admin can remove user from tenant (soft delete) via DELETE /tenants/:id/users/:userId
5. Invite user button opens modal with invitation form
6. Pending join requests shown in separate tab/section with approve/reject actions
7. Non-admin users see read-only team list without management controls

```sql
-- users table
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
    email VARCHAR(255) NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    first_name VARCHAR(100),
    last_name VARCHAR(100),
    avatar_url TEXT,
    status VARCHAR(50) DEFAULT 'active',  -- active, inactive, suspended
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(tenant_id, email)
);

-- user_tenant_roles table
CREATE TABLE user_tenant_roles (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    tenant_id UUID NOT NULL REFERENCES tenants(id) ON DELETE CASCADE,
    role VARCHAR(50) NOT NULL,  -- admin, user, viewer
    created_at TIMESTAMP DEFAULT NOW(),
    UNIQUE(user_id, tenant_id, role)
);
```

**Query for User List**:
```sql
SELECT 
    u.id, 
    u.email, 
    u.first_name, 
    u.last_name,
    u.status,
    u.created_at,
    utr.role
FROM users u
JOIN user_tenant_roles utr ON u.id = utr.user_id
WHERE u.tenant_id = :tenantId
AND utr.tenant_id = :tenantId
ORDER BY u.created_at DESC;
```

**Error Responses**:

### Team Management Component Implementation

[Source: AC 2, 7]

```typescript
// team-management.component.ts
@Component({
  selector: 'app-team-management',
  templateUrl: './team-management.component.html',
  styleUrls: ['./team-management.component.scss']
})
export class TeamManagementComponent implements OnInit {
  users: User[] = [];
  joinRequests: JoinRequest[] = [];
  loading = true;
  isAdmin = false;
  currentUserId = '';
  selectedTab = 0;

  constructor(
    private teamService: TeamService,
    private authService: AuthService,
    private dialog: MatDialog,
    private snackBar: MatSnackBar
  ) {}

  ngOnInit() {
    this.checkAdminRole();
    this.loadUsers();
    if (this.isAdmin) {
      this.loadJoinRequests();
    }
  }

  checkAdminRole() {
    const user = this.authService.getCurrentUser();
    this.currentUserId = user?.id;
    this.isAdmin = user?.roles?.includes('admin');
  }

  async loadUsers() {
    this.loading = true;
    try {
      this.users = await this.teamService.getTeamMembers();
    } catch (error) {
      this.snackBar.open('Error loading team members', 'Close', { duration: 3000 });
    } finally {
      this.loading = false;
    }
  }

  async loadJoinRequests() {
    this.joinRequests = await this.teamService.getJoinRequests();
  }

  openInviteDialog() {
    const dialogRef = this.dialog.open(InviteUserDialogComponent);
    dialogRef.afterClosed().subscribe(result => {
      if (result) {
        this.loadUsers();
      }
    });
  }

  openChangeRoleDialog(user: User) {
    const dialogRef = this.dialog.open(ChangeRoleDialogComponent, {
      data: { user }
    });
    dialogRef.afterClosed().subscribe(async (newRole) => {
      if (newRole) {
        await this.changeUserRole(user, newRole);
      }
    });
  }

  async changeUserRole(user: User, newRole: string) {
    try {
      await this.teamService.changeUserRole(user.id, newRole);
      this.snackBar.open('User role updated', 'Close', { duration: 3000 });
      this.loadUsers();
    } catch (error) {
      this.snackBar.open('Error updating role', 'Close', { duration: 3000 });
    }
  }

  openRemoveDialog(user: User) {
    const dialogRef = this.dialog.open(RemoveUserDialogComponent, {
      data: { user }
    });
    dialogRef.afterClosed().subscribe(async (confirmed) => {
      if (confirmed) {
        await this.removeUser(user);
      }
    });
  }

  async removeUser(user: User) {
    try {
      await this.teamService.removeUser(user.id);
      this.snackBar.open('User removed from organization', 'Close', { duration: 3000 });
      this.users = this.users.filter(u => u.id !== user.id);
    } catch (error) {
      this.snackBar.open('Error removing user', 'Close', { duration: 3000 });
    }
  }

  isCurrentUser(userId: string): boolean {
    return userId === this.currentUserId;
  }
}
```

### Business Logic Rules

[Source: AC 3, 4, derived requirements]

1. **Self-Protection**: Admin cannot change their own role or remove themselves
2. **Role Validation**: Only 'admin' and 'user' roles allowed
3. **Tenant Isolation**: Users can only manage users in their own tenant
4. **Admin Authority**: Only tenant admins can modify roles or remove users
5. **Last Admin Prevention**: Prevent removal of last admin (optional but recommended)
6. **Cascade Delete**: When user removed from tenant, delete user_tenant_roles entry

### Authorization Guards

[Source: AC 7, architecture/authentication-multi-tenancy.md]

**Backend Validation**:
```typescript
@Patch('users/:id/role')
@UseGuards(JwtAuthGuard, RolesGuard)
@Roles('admin')
async changeUserRole(
  @Param('id') userId: string,
  @Body() dto: ChangeRoleDto,
  @CurrentUser() admin: any
) {
  // Prevent changing own role
  if (userId === admin.userId) {
    throw new ConflictException('Cannot change your own role');
  }

  // Verify user is in same tenant
  const user = await this.usersService.findOne(userId);
  if (user.tenantId !== admin.tenantId) {
    throw new ForbiddenException('User not in your organization');
  }

  return this.usersService.changeRole(userId, dto.role);
}
```
