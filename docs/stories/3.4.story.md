# Story 3.4: Notes API - File Attachments

## Status
Draft

## Story

**As a** user,
**I want** to attach files to notes,
**so that** I can keep related documents together.

## Acceptance Criteria

1. POST /notes/:id/attachments endpoint accepts file_id from Core File Service
2. Creates note_attachments record linking note to file
3. GET /notes/:id includes attachments array with file metadata
4. DELETE /notes/:id/attachments/:attachmentId removes attachment from note
5. Attachment size limit enforced: 25MB per file, 100MB total per note
6. Deleting note cascades soft-delete to attachments (deleted_at set)
7. Authorization: Only note owner/admin can manage attachments

### Inter-Service Communication Pattern

**Calling Core Service for File Metadata**:  
[Source: architecture/api-contracts-communication.md#inter-service-communication]

```typescript
// files-client.service.ts
@Injectable()
export class FilesClientService {
  constructor(private httpService: HttpService) {}

  async getFileMetadata(fileId: string, token: string): Promise<FileMetadata> {
    const coreServiceUrl = process.env.CORE_SERVICE_URL || 'http://localhost:3000';
    
    try {
      const response = await this.httpService
        .get(`${coreServiceUrl}/api/v1/files/${fileId}`, {
          headers: { Authorization: `Bearer ${token}` }
        })
        .toPromise();

      return response.data.data;
    } catch (error) {
      if (error.response?.status === 404) {
        throw new NotFoundException(`File ${fileId} not found`);
      }
      if (error.response?.status >= 500) {
        throw new ServiceUnavailableException('Core Service unavailable');
      }
      throw error;
    }
  }

  async validateFileOwnership(fileId: string, tenantId: string, token: string): Promise<boolean> {
    const file = await this.getFileMetadata(fileId, token);
    return file.tenant_id === tenantId;
  }

  async getMultipleFileMetadata(fileIds: string[], token: string): Promise<FileMetadata[]> {
    // Batch fetch for performance
    const promises = fileIds.map(id => this.getFileMetadata(id, token));
    return Promise.all(promises);
  }
}
```

### Attachment Size Validation

**Size Limits**:  
[Source: AC 5]

- **Per File**: 25MB (25 * 1024 * 1024 = 26,214,400 bytes)
- **Total per Note**: 100MB (100 * 1024 * 1024 = 104,857,600 bytes)

**Validation Logic**:

```typescript
// attachments.service.ts
async validateAttachmentSize(noteId: string, newFileSize: number, token: string): Promise<void> {
  const MAX_FILE_SIZE = 25 * 1024 * 1024;  // 25MB
  const MAX_TOTAL_SIZE = 100 * 1024 * 1024;  // 100MB
  
  // Check individual file size
  if (newFileSize > MAX_FILE_SIZE) {
    throw new BadRequestException(`File size exceeds 25MB limit. File size: ${(newFileSize / 1024 / 1024).toFixed(2)}MB`);
  }
  
  // Get all existing attachments for note
  const attachments = await this.attachmentsRepo.find({
    where: { 
      note_id: noteId,
      deleted_at: IsNull()  // Only count active attachments
    }
  });
  
  // Fetch file sizes from Core Service
  const fileIds = attachments.map(a => a.file_id);
  const fileMetadata = await this.filesClientService.getMultipleFileMetadata(fileIds, token);
  
  // Calculate total size
  const currentTotalSize = fileMetadata.reduce((sum, file) => sum + file.file_size, 0);
  const newTotalSize = currentTotalSize + newFileSize;
  
  if (newTotalSize > MAX_TOTAL_SIZE) {
    throw new BadRequestException(
      `Total attachment size would exceed 100MB limit. ` +
      `Current: ${(currentTotalSize / 1024 / 1024).toFixed(2)}MB, ` +
      `New file: ${(newFileSize / 1024 / 1024).toFixed(2)}MB, ` +
      `Total: ${(newTotalSize / 1024 / 1024).toFixed(2)}MB`
    );
  }
}
```

### Soft Delete Cascade

**Cascade Logic**:  
[Source: AC 6]

```typescript
// notes.service.ts
async softDelete(id: string, tenantId: string, userId: string): Promise<void> {
  const note = await this.findOne(id, tenantId);
  
  // Authorization check
  if (note.user_id !== userId && !user.roles.includes('admin')) {
    throw new ForbiddenException('You can only delete your own notes');
  }
  
  // Soft delete note
  await this.notesRepo.update(id, { deleted_at: new Date() });
  
  // Cascade soft delete to attachments
  await this.attachmentsRepo.update(
    { note_id: id },
    { deleted_at: new Date() }
  );
}
```

### Authorization Pattern

**Attachment Management Authorization**:  
[Source: AC 7]

```typescript
// Same pattern as notes and folders
function canManageAttachment(note: Note, user: JwtPayload): boolean {
  return note.user_id === user.userId || user.roles.includes('admin');
}

// Usage in controller
@Post(':id/attachments')
async addAttachment(
  @Param('id') noteId: string,
  @Body() dto: CreateAttachmentDto,
  @CurrentUser() user: JwtPayload,
  @Headers('authorization') authHeader: string
) {
  const note = await this.notesService.findOne(noteId, user.tenantId);
  
  if (!canManageAttachment(note, user)) {
    throw new ForbiddenException('You can only add attachments to your own notes');
  }
  
  const token = authHeader.replace('Bearer ', '');
  return this.attachmentsService.create(noteId, dto, user.tenantId, token);
}
```
