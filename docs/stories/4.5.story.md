## Story

**As a** user,
**I want** to comment on tasks and see activity history,
**so that** I can collaborate with team members.

## Acceptance Criteria

1. POST /tasks/:taskId/comments endpoint creates comment with content, user_id (from JWT)
2. GET /tasks/:id/comments endpoint returns comments ordered by created_at
3. PATCH /comments/:id endpoint allows comment author to edit content
4. DELETE /comments/:id soft deletes comment (only author or admin)
5. Task activity log tracks: created, assigned, moved, completed (column-based)
6. GET /tasks/:id/activity endpoint returns activity timeline
7. Comments and activity scoped to tenant automatically

## Dev Notes

### Architecture Context

**Service**: Kanban Service API  
[Source: architecture/component-architecture.md#kanban-service]

**Comments**:  
Comments belong to tasks. Only author or admin can edit/delete.

**Activity Logging**:  
Track all significant task changes for audit trail and collaboration context.

### Previous Story Insights

**Story 4.1**: Database schema with task_comments table  
**Story 4.4**: Task CRUD operations and authorization patterns

### Activity Types

- **created**: Task created
- **assigned**: Task assigned to user
- **moved**: Task moved between columns
- **completed**: Task moved to "Done" column (if applicable)
- **updated**: Task fields updated (title, description, priority, due_date)

### API Endpoints

**POST /api/v1/tasks/:taskId/comments**  
Create comment

Request:
```json
{
  "content": "This looks good, let's proceed"
}
```

**GET /api/v1/tasks/:id/comments**  
Get comments (ordered by created_at ASC)

**PATCH /api/v1/comments/:id**  
Update comment (author or admin only)

**DELETE /api/v1/comments/:id**  
Delete comment (author or admin only)

**GET /api/v1/tasks/:id/activity**  
Get activity timeline (ordered by created_at DESC)

Response:
```json
{
  "success": true,
  "data": [
    {
      "id": "activity-uuid",
      "action_type": "moved",
      "user_id": "user-uuid",
      "old_value": "To Do",
      "new_value": "In Progress",
      "created_at": "2025-01-14T10:00:00Z"
    }
  ]
}
```
