# Story 5.6: Production Deployment to DigitalOcean

## Status
Draft

## Story

**As a** platform operator,
**I want** production deployment on DigitalOcean infrastructure,
**so that** the platform is accessible to customers.

## Acceptance Criteria

1. Managed PostgreSQL databases provisioned: core_db, notes_db, kanban_db (3 separate instances)
2. DigitalOcean Spaces bucket configured for file storage
3. Droplets or App Platform configured for each service with auto-scaling (if App Platform)
4. Domain DNS configured: mydomain.com, notes.mydomain.com, kanban.mydomain.com, api.mydomain.com
5. SSL certificates installed and auto-renewal configured
6. Database backups scheduled (daily snapshots with 7-day retention)
7. Production deployment verified: all services accessible, health checks passing

## Tasks / Subtasks

- [ ] Task 1: Provision Core Infrastructure (AC: 1, 2, 3)
  - [ ] Create managed PostgreSQL instances for Core, Notes, Kanban with proper sizing and network restrictions
  - [ ] Configure DigitalOcean Spaces bucket and access keys for file uploads
  - [ ] Set up App Platform apps or Droplets for each API/UI service, configuring scaling rules and environment variables

- [ ] Task 2: Configure Networking & Domains (AC: 3, 4, 5)
  - [ ] Map domains (`mydomain.com`, `notes.mydomain.com`, `kanban.mydomain.com`, `api.mydomain.com`) to deployed services via DNS records
  - [ ] Configure Nginx or App Platform routes to direct traffic to appropriate containers/services
  - [ ] Install TLS certificates with automatic renewal (Let's Encrypt or DO-managed certs)

- [ ] Task 3: Secure Database Connectivity (AC: 1, 6)
  - [ ] Restrict PostgreSQL access to application hosts via firewall/VPC settings
  - [ ] Configure daily automated backups/snapshots with 7-day retention and test restoration
  - [ ] Store database credentials securely (GitHub secrets, DO environment variables)

- [ ] Task 4: Deploy Application Artifacts (AC: 3, 7)
  - [ ] Use CI/CD pipeline (Story 5.2) to promote builds to production environment
  - [ ] Run database migrations for each service against managed databases
  - [ ] Validate health checks and smoke-test critical flows (auth login, notes CRUD, kanban board operations)

- [ ] Task 5: Documentation & Handoff (AC: 2, 4, 5, 6, 7)
  - [ ] Update `docs/deployment/production-deployment.md` detailing provisioning steps, credentials storage, and rollback plan
  - [ ] Record DNS, SSL, and backup configurations with renewal schedules
  - [ ] Capture go-live checklist and verification evidence (screenshots, commands)

- [ ] Task 6: Post-Deployment Validation (AC: 7)
  - [ ] Monitor production environment for at least 24 hours ensuring uptime and error rates acceptable
  - [ ] Ensure monitoring/alerting from Story 5.5 targets production resources
  - [ ] Gather stakeholder sign-off confirming services meet production readiness
