# Story 2.7: Dashboard UI - Service Cards & Navigation

## Status
Ready for Review

## Story

**As a** logged-in user,
**I want** a dashboard showing available services,
**so that** I can navigate to the tools I need.

## Acceptance Criteria

1. Angular dashboard at mydomain.com/dashboard displays service cards
2. Each card shows: service icon, name, description, status (Available/Locked)
3. Available services have "Open" button redirecting to service subdomain
4. Locked services have "Request Access" button opening request modal
5. Service availability determined by JWT enabledServices claim
6. Top navigation includes: company name, user avatar/menu, logout option
7. Responsive grid layout: 3 columns desktop, 2 columns tablet, 1 column mobile

### JWT Service Integration

[Source: AC 5, Story 2.2, architecture/api-contracts-communication.md]

**Extract Enabled Services from JWT**:
```typescript
// services/auth.service.ts (extend existing)
import { JwtHelperService } from '@auth0/angular-jwt';

@Injectable({ providedIn: 'root' })
export class AuthService {
  private jwtHelper = new JwtHelperService();

  getEnabledServices(): string[] {
    const token = localStorage.getItem('auth_token');
    if (!token) return [];
    
    try {
      const payload = this.jwtHelper.decodeToken(token);
      return payload.enabledServices || [];
    } catch (error) {
      console.error('Error decoding JWT:', error);
      return [];
    }
  }

  getCurrentUser(): User | null {
    const token = localStorage.getItem('auth_token');
    if (!token) return null;
    
    try {
      const payload = this.jwtHelper.decodeToken(token);
      return {
        id: payload.sub,
        email: payload.email,
        name: `${payload.firstName || ''} ${payload.lastName || ''}`.trim(),
        tenantId: payload.tenantId,
        roles: payload.roles
      };
    } catch (error) {
      return null;
    }
  }
}
```

```typescript
@Component({
  selector: 'app-dashboard',
  templateUrl: './dashboard.component.html',
  styleUrls: ['./dashboard.component.scss']
})
export class DashboardComponent implements OnInit {
  services: ServiceViewModel[] = [];
  enabledServices: string[] = [];
  loading = true;

  constructor(
    private authService: AuthService
  ) {}

  ngOnInit() {
    this.enabledServices = this.authService.getEnabledServices();
    this.loadServices();
  }

  loadServices() {
    this.services = SERVICE_CATALOG.map(service => ({
      ...service,
      isAvailable: this.enabledServices.includes(service.name),
      status: this.enabledServices.includes(service.name) 
        ? 'Available' 
        : 'Locked'
    }));
    this.loading = false;
  }

  openService(service: ServiceViewModel) {
    if (service.isAvailable && !service.comingSoon) {
      window.location.href = service.url;
    }
  }

  requestAccess(service: ServiceViewModel) {
    // Open modal or show message
    // Future: Send request to admin
  }
}
```

**Top Nav Component Logic**:
```typescript
// top-nav.component.ts
@Component({
  selector: 'app-top-nav',
  templateUrl: './top-nav.component.html',
  styleUrls: ['./top-nav.component.scss']
})
export class TopNavComponent implements OnInit {
  tenantName = '';
  userName = '';
  userEmail = '';
  userInitials = '';

  constructor(
    private authService: AuthService,
    private router: Router
  ) {}

  ngOnInit() {
    const user = this.authService.getCurrentUser();
    if (user) {
      this.userName = user.name;
      this.userEmail = user.email;
      this.userInitials = this.getInitials(user.name);
    }
    
    // Get tenant name from JWT or API
    this.tenantName = this.getTenantName();
  }

  getInitials(name: string): string {
    return name
      .split(' ')
      .map(part => part[0])
      .join('')
      .toUpperCase()
      .substring(0, 2);
  }

  getTenantName(): string {
    // Extract from JWT or make API call
    return 'Acme Corp'; // Placeholder
  }

  logout() {
    this.authService.logout();
    this.router.navigate(['/login']);
  }

  goToProfile() {
    this.router.navigate(['/profile']);
  }

  goToSettings() {
    this.router.navigate(['/settings']);
  }

  toggleSidebar() {
    // Toggle sidebar if exists
  }
}
```

```typescript
// guards/auth.guard.ts
@Injectable({ providedIn: 'root' })
export class AuthGuard implements CanActivate {
  constructor(
    private authService: AuthService,
    private router: Router
  ) {}

  canActivate(): boolean {
    if (this.authService.isAuthenticated()) {
      return true;
    }
    
    this.router.navigate(['/login']);
    return false;
  }
}
```

### Security Review

**CRITICAL VULNERABILITY - SECURITY-001 (HIGH SEVERITY)**

**Location**: `apps/core-ui/src/app/core/services/auth.service.ts:127-136`

**Issue**: Manual JWT decoding without security validation
```typescript
private decodeToken(token: string): any {
  const parts = token.split('.');
  if (parts.length !== 3) {
    throw new Error('Invalid token format');
  }
  const payload = parts[1];
  const decoded = atob(payload);
  return JSON.parse(decoded);
}
```

**Vulnerabilities:**
- No signature verification - attacker can forge tokens
- No expiry (exp) validation - expired tokens accepted
- No issuer (iss) validation
- No audience (aud) validation
- Trusts client-side token implicitly

**Impact**: Critical - users could gain unauthorized access to services by forging JWT tokens

**Recommended Fix**:
```typescript
// Install: npm install @auth0/angular-jwt
import { JwtHelperService } from '@auth0/angular-jwt';

private jwtHelper = new JwtHelperService();

private decodeToken(token: string): any {
  if (this.jwtHelper.isTokenExpired(token)) {
    throw new Error('Token expired');
  }
  return this.jwtHelper.decodeToken(token);
}
```

**Note**: Signature verification should happen server-side. Client should validate expiry only.
