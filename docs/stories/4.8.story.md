# Story 4.8: Kanban UI - Drag-and-Drop Workflow

## Status
Approved

## Story

**As a** user,
**I want** to drag-and-drop tasks between columns,
**so that** I can update task status intuitively.

## Acceptance Criteria

1. Tasks draggable within column to reorder position
2. Tasks draggable between columns to change status
3. Drag uses PrimeNG drag-drop or Angular CDK drag-drop
4. Drop triggers PATCH /tasks/:id updating column_id and position
5. Optimistic UI update: Card moves immediately, reverts on API error
6. Visual feedback: Drop zones highlight during drag, card shows "grabbing" cursor
7. Keyboard alternative: Arrow keys + Enter to move tasks (accessibility)

### Drag-and-Drop Implementation

**PrimeNG Approach**:
```typescript
// task-card.component.html
<div 
  pDraggable="task"
  [dragData]="task"
  (onDragStart)="onDragStart()"
  (onDragEnd)="onDragEnd()">
  <!-- task content -->
</div>

// column.component.html
<div 
  pDroppable="task"
  (onDrop)="onTaskDrop($event)"
  (onDragEnter)="onDragEnter()"
  (onDragLeave)="onDragLeave()">
  <!-- column content -->
</div>
```

**Angular CDK Approach**:
```typescript
// task-card.component.html
<div 
  cdkDrag
  [cdkDragData]="task"
  (cdkDragStarted)="onDragStart()"
  (cdkDragEnded)="onDragEnd()">
  <!-- task content -->
</div>

// column.component.html
<div cdkDropList (cdkDropListDropped)="onTaskDrop($event)">
  <div *ngFor="let task of tasks" cdkDrag>
    <!-- task card -->
  </div>
</div>
```

### API Endpoint

**PATCH /api/v1/tasks/:id/move**  
[Source: Story 4.4]

Request:
```json
{
  "columnId": "new-column-uuid",
  "position": 0
}
```

Response:
```json
{
  "success": true,
  "data": {
    "id": "task-uuid",
    "column_id": "new-column-uuid",
    "position": 0,
    ...
  }
}
```

### Optimistic Update Pattern

1. User drags task
2. Update local state immediately (move task in array)
3. Call API in background
4. If success: keep new state
5. If error: revert to original state, show error message

### Accessibility

**Keyboard Navigation**:
- Tab: navigate between tasks
- Arrow keys: move focus up/down/left/right
- Enter: activate (move task or open menu)
- Escape: cancel operation

**ARIA Labels**:
- `aria-label="Task: {title}"`
- `aria-describedby="task-description"`
- `role="button"` for draggable items
