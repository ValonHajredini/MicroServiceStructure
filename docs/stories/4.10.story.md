# Story 4.10: Kanban UI - Real-Time Updates Integration

## Status
Draft

## Story

**As a** user,
**I want** to see board changes made by teammates in real-time,
**so that** I have current view of project status.

## Acceptance Criteria

1. Client establishes WebSocket connection (or polling interval) on board load
2. Incoming task create event adds card to appropriate column
3. Incoming task move event animates card to new column/position
4. Incoming comment event updates task comment count badge
5. Incoming column add/reorder event updates board layout
6. Visual indicator shows "X updated this board" toast notification
7. User's own actions don't trigger redundant update notifications

### WebSocket Client Implementation

**Socket.io Client**:
```typescript
// websocket.service.ts
import { io, Socket } from 'socket.io-client';

@Injectable()
export class WebSocketService {
  private socket: Socket;

  connect(boardId: string) {
    this.socket = io(`${API_URL}/kanban`, {
      auth: { token: this.authService.getToken() }
    });

    this.socket.emit('joinBoard', boardId);

    this.socket.on('task:created', (task) => {
      this.realtimeUpdateService.handleTaskCreated(task);
    });

    this.socket.on('task:moved', (event) => {
      this.realtimeUpdateService.handleTaskMoved(event);
    });
  }

  disconnect() {
    this.socket?.disconnect();
  }
}
```

### Polling Implementation

**Polling Service**:
```typescript
// polling.service.ts
@Injectable()
export class PollingService {
  private pollingInterval: any;
  private lastUpdate: Date = new Date();

  startPolling(boardId: string) {
    this.pollingInterval = setInterval(() => {
      this.boardService.getUpdatesSince(boardId, this.lastUpdate)
        .subscribe(updates => {
          this.processUpdates(updates);
          this.lastUpdate = new Date();
        });
    }, 5000);
  }

  stopPolling() {
    if (this.pollingInterval) {
      clearInterval(this.pollingInterval);
    }
  }
}
```

### Update Event Handlers

**Task Created**:
```typescript
handleTaskCreated(task: Task) {
  // Find column by column_id
  const column = this.columns.find(c => c.id === task.column_id);
  if (column) {
    column.tasks.push(task);
    this.showToast(`New task created: ${task.title}`, false);
  }
}
```

**Task Moved**:
```typescript
handleTaskMoved(event: TaskMovedEvent) {
  // Remove from source column
  const sourceColumn = this.columns.find(c => c.id === event.old_column_id);
  sourceColumn.tasks = sourceColumn.tasks.filter(t => t.id !== event.task_id);

  // Add to target column
  const targetColumn = this.columns.find(c => c.id === event.new_column_id);
  targetColumn.tasks.splice(event.new_position, 0, event.task);

  // Animate movement
  this.animateTaskMove(event.task_id, event.new_column_id);

  this.showToast(`Task moved to ${targetColumn.title}`, false);
}
```

### Conflict Resolution

**Strategy**: Remote update wins (refresh from server)

When conflict detected:
1. Show warning: "This task was updated by another user"
2. Refresh task data from server
3. Preserve user's local changes if possible
4. If not possible, show conflict resolution dialog
